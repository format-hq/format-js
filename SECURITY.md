# Security

## Reporting a vulnerability

Use [GitHub's private advisory form](https://github.com/format-hq/format-js/security/advisories/new) or email [security@format.dev](mailto:security@format.dev). Please keep vulnerability reports out of public issues.

Include the affected package and version, what you found, and how to reproduce it. A proof of concept is helpful but optional.

We acknowledge reports within three working days. We will keep you informed of our findings, planned fixes, and timing. We credit reporters in security advisories unless they ask us not to.

## What is in scope

Current versions of the packages published from this repository, the rendering engine, and the hosted API are all in scope. Use the same reporting channels for each.

Reports that require an already-compromised machine, or provide scanner output without a demonstrated impact, are out of scope.

## Supported versions

During pre-1.0 development, security fixes ship in the current release. We do not backport them to older versions. Upgrade to the current release to receive fixes.
