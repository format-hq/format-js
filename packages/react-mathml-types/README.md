# @format.dev/react-mathml-types

React JSX TypeScript declarations for MathML elements.

This package augments React's JSX types so MathML elements such as `<math>`, `<mrow>`, `<mi>`, `<mo>`, `<semantics>`, `<annotation>`, and `<annotation-xml>` can be used in `.tsx` files without TypeScript errors.

## Installation

```sh
npm install "@format.dev/react-mathml-types"
```

Then import the module anywhere in your app code:

```js
import '@format.dev/react-mathml-types'
```
